# 蓝色城堡 · S00 世界总览

《蓝色城堡》交互叙事网站的第一阶段原型。当前仓库实现 S00 世界总览页面，用一张 16:9 场景图、SVG 多边形热点和低频环境动画构成可探索的叙事入口。

## 当前内容

- 全屏 16:9 世界总览，画面等比居中且不拉伸
- 城堡、花园、热气球、小镇、瀑布五个交互热点
- 热点悬停时显示柔和的白色边缘光与场景名称
- 城堡和花园支持平滑聚焦、占位场景及返回总览动画
- 热气球和小镇显示未开放提示，瀑布显示观察文字
- 双层雾气、背景呼吸、树影、热气球、水光和窗灯等低频环境动画
- 鼠标轻微视差、键盘操作和移动端二次触摸确认
- 支持减少动态模式，并使用本地存储保存访问状态和动态设置
- 页面进入或返回动画期间锁定其他热点与名称提示，避免误触

## 文件结构

```text
blue-castle-s00/
├─ index.html                 页面结构
├─ styles.css                 视觉样式与环境动画

└─ assets/

   ├─ s00-hotspots.json       热点名称、坐标与行为

```

## 本地运行

页面支持直接打开 `index.html`。为了获得与部署环境一致的行为，也可以在项目目录运行本地静态服务器：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000/`。

## 操作方式

- 鼠标：移动到热点查看名称，点击触发场景行为
- 键盘：使用 `Tab` 选择热点，按 `Enter` 或 `Space` 触发，按 `Esc` 返回总览
- 触摸屏：第一次点击显示名称，第二次点击触发
- 右上角按钮：手动开启或关闭“减少动态”

## 热点行为

| ID | 场景 | 当前行为 |
| --- | --- | --- |
| H01 | 蓝色城堡 | 聚焦并显示 `S01 山路与城堡外观` 占位界面 |
| H02 | 花园 | 聚焦并显示 `S02 后花园与温室` 占位界面 |
| H03 | 热气球 | 显示未开放提示 |
| H04 | 小镇 | 显示未开放提示 |
| H05 | 瀑布 | 显示观察文字，不切换页面 |
